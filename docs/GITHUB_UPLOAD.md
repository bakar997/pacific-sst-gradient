# Repository publication and updates

The project is published at [bakar997/pacific-sst-gradient](https://github.com/bakar997/pacific-sst-gradient).

For subsequent updates:

1. Use a fresh checkout of the current repository and follow the setup and analysis commands in `README.md`.
2. Preserve the code, data, notebook outputs, figures, methods, limitations, licence, citations, and contributor acknowledgements.
3. Include `data/raw/` and `data/provenance.json`; the small frozen subsets make the analysis reproducible. Exclude `.venv`, `__pycache__` and notebook checkpoints, as specified in `.gitignore`.
4. Run the existing tests and review changes to numerical outputs if data or methods change.
5. Check that README images load and the notebook displays its saved outputs, then commit and push the reviewed changes.

This is an observational analysis. It does not perform climate-model attribution. Potential extensions described in the documentation are not completed analyses.
